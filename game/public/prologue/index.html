场景规格

依据：队友《场景生图提示词 v3 · 恐怖版》「1｜序厅」【本场】+ 连贯锁 + 负面词。空间、主色、光源、纸扎人、湿脚印、贴地香烟全部按提示词；S0 清单只借编号与尺寸，不采纳与负面词冲突的「可读须知」「角色实体」「低位暖光」。

场景内不写清晰文字：水牌 / 匾额只留模糊笔痕；剧本台词一律走 DOM 字幕，不往墙面、生死簿上贴可读的字。无经幡、无暖黄火焰（灯笼与香头都是青白冷火）。业秤留给二殿。
v28 与 v3 的一处冲突：按 mina 要求加了判官崔珏这位可对话的角色实体，并沿用 v26 的「看得见人脸」。?nojudge=1 可完全移除判官、?plainface=1 去掉瞳孔，回到 v3 严格版；v3 原文未改动。
v29 造型：判官改坐在案侧官帽椅上，补垂缨冠横簪、暗绣回纹、袖口飞墨、腰侧印匣、簿册装帧与案上文房；?v28judge=1 可回到站立版对照。
v30 精修：幞头换圆帽筒 + 短展脚，去掉腿部圆端盖、袍摆亮边与脸片硬椭圆描边，交领收成 Y 字，判官机位整体拉远。

走动：W / S 前后，A / D 左右，Q / E 升降，Shift 快走，R 回长凳前；左键转视角、滚轮缩放，右键平移已禁用，相机锁在廊内。

对白与交互：走近案边判官约 2.2 m 自动触发对话（不再一开局就开口），「我不认」是唯一选项（没有「认」）；走开再回来可再听。点判官本人也能对谈，F 重唤申辩，点击 / 空格推进，T 开卷宗，Esc 收起。9 处可点观察点各有一句剧本 / v3 台词。?noapproach=1 回到一开局开口，?nodlg=1 回纯无字版。
