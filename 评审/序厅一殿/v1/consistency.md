# 序厅 / 第一殿 ↔ 四五六殿 跨场景风格一致性专项 v1

- 证据基线：commit **922a9c5**
- 对照组：game/artifacts/prologue/{prologue-start,prologue-judge,prologue-door,first-hall-entry,first-hall-vision,first-hall-solved}.png ↔ game/artifacts/{act4-medicine.png,act5-palace.png}（四五六殿为既有基线图，非本轮重拍）
- 结论：**修改后复审** — 两处硬断裂（判官/纸人的人形资产语汇、第一殿 HUD），一处主调偏移（序厅）；其余语汇连贯。

## 1. 色温与光

| 场景 | 主调 | 与 v3 对照 |
|---|---|---|
| 序厅 | 青灰绿+冷白窗光 | 应为"灰白与旧纸色"；实测纸色族 <1.5%，被一殿色系同化 |
| 一殿 | 青铜绿+墨蓝+青白焰 | ✓ 达标 |
| 四殿（对照） | 暖棕+药草绿 | 各场差异，允许 |
| 五殿（对照） | 近黑+九盏幽绿灯点 | 各场差异，允许 |

- 序厅→一殿色温几乎无跳变（都偏青绿），问题不是"衔接不上"而是"序厅没有自己的色"。一殿→四殿色温大跳属设计内（v3 允许七关不同色），不算违约。
- 冷火纪律一致：序厅/一殿/五殿均无暖黄火 ✓。

## 2. 材质语汇

- 木/石/纸/铜四族贯穿七个场景，量测上木质族在序厅 77–84%、一殿 71–74%，同族占主导，语汇连贯 ✓。
- 断裂点：**人形资产**。判官（圆顶礼帽+卡通脸+纯黑块状身体）与纸扎人（描边五官+点睛）是低模卡通风，与四五六殿"写实暗调衙署"不属于同一套视觉；四五六殿无近景人形可对照，但即便与序厅自身环境（写实柱础、窗格）相比，人形也明显是另一档做工。用户点名"判官丑"，根因即此断层。

## 3. HUD

- 序厅：左上小标题块+左下键位+右下两钮 — 与四殿/五殿（左上"还魂路引+殿名+目标"、底部"点击画面·锁定鼠标"）**同构** ✓。
- 一殿：右侧常驻"殿中陈设"大面板（含 S1-xx、FOV、尺寸表等开发参数）— 与四五六殿极简 HUD **严重断裂**，是全作 HUD 唯一破口。
- 一殿左上标题块样式（殿名+壹印+英文小字）与序厅一致，这部分可保留。

## 4. 叙事语汇

- 官僚阴司语汇连贯：便民司取号机（序厅）→ 孽镜台公堂（一殿）→ 药局柜台（四殿）→ 九宫石板（五殿），衙署→刑狱→司职的递进成立。
- 恐怖暗示手法不一致：序厅/一殿有雾与冷光暗示，但 v3 要求的"刚有人离开"细节（湿脚印、坐痕、掌印）未落地，与四殿"生活痕迹"密度相比偏空。
